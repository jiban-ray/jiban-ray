## 2. What I'm Working On

### Current PhD Research

**Trustworthiness Assessment Framework for Distributed AI Systems Based on Reliability, Robustness, and Trust (RRT)**

My doctoral research aims to develop and experimentally validate a unified framework for assessing distributed AI systems using measurable reliability, robustness, and trust indicators.

The research investigates participant-level and system-level assessment in federated learning environments involving heterogeneous data, unreliable participants, and potentially adversarial conditions.

**Research focus:**
- Measurable indicators for reliability, robustness, and trust
- Trustworthiness assessment in federated learning
- Evaluation under failures and adversarial conditions
- Reproducible experiments and comparative analysis
